This project is a small project that I learn about using algorithms to built a physical device to calculate valuable wellness data for pets.
Uses the Xiao-nRF52840 and MAX30102 sensors for getting the instantaneous data, and data would first go through a simple filter,
then after the data is sent to the device(such as user's phone), it then calculates the data and display to the user.
The goal is to keep the most relevant data the user look for, while minimizing the size of the collar as much as possible. 
The current size of the device is around 3x3x5cm. 
It display the daily activity level and sleep level of the pet. 
I paused the project realizing it takes too much money on getting certified for a bluetooth device. As well as the the sensor cannot 
collect bpm in a stable state due to the noises caused by the hair of the pet.
